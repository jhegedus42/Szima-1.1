HU: Legyen f egy függvény az A halmazból egy másik B halmazba, így írjuk: f : A → B.

SRC: Awodey §1.2

HU: Tegyük fel most, hogy van egy g : B → C függvényünk is,
EN: Now suppose we also have a function g : B → C,
SRC: Awodey §1.2

HU: ekkor létezik egy g ◦ f : A → C kompozíciófüggvény, amelyet a következőképpen adunk meg: (g ◦ f)(a) = g(f(a)), a ∈ A. (1.1)
EN: then there is a composite function g ◦ f : A → C, given by (g ◦ f)(a) = g(f(a)) a ∈ A. (1.1)
SRC: Awodey §1.2

HU: Nos, a függvények kompozíciójának ez a „◦" művelete asszociatív, a következőképpen.
EN: Now this operation "◦" of composition of functions is associative, as follows.
SRC: Awodey §1.2

HU: Ha van egy további h : C → D függvényünk
EN: If we have a further function h : C → D
SRC: Awodey §1.2

HU: és képezzük az h◦g és g◦f kompozíciókat, akkor összehasonlíthatjuk a (h◦g)◦f és h◦(g◦f) kompozíciókat, ahogy a fenti diagram jelzi.
EN: and form h◦g and g ◦f then we can compare (h◦g)◦f and h◦(g ◦f ) as indicated in the above diagram.
SRC: Awodey §1.2

HU: Kiderül, hogy ez a két függvény mindig azonos: (h ◦ g) ◦ f = h ◦ (g ◦ f),
EN: It turns out that these two functions are always identical, (h ◦ g) ◦ f = h ◦ (g ◦ f )
SRC: Awodey §1.2

HU: mivel bármely a ∈ A esetén fennáll ((h ◦ g) ◦ f)(a) = h(g(f(a))) = (h ◦ (g ◦ f))(a) az (1.1) felhasználásával.
EN: since for any a ∈ A, we have ((h ◦ g) ◦ f)(a) = h(g(f(a))) = (h ◦ (g ◦ f))(a) using (1.1).
SRC: Awodey §1.2

HU: Egyébként ez természetesen éppen azt jelenti, hogy két függvény egyenlő: minden argumentumra ugyanazt az értéket veszik fel.
EN: By the way, this is of course what it means for two functions to be equal: for every argument, they have the same value.
SRC: Awodey §1.2

SRC: Awodey §1.2

HU: Ezek az identitásfüggvények „egységelemként" viselkednek a ◦ kompozícióműveletre nézve, az absztrakt algebra értelemben.

SRC: Awodey §1.2

HU: Azaz f ◦ 1A = f = 1B ◦ f bármely f : A → B esetén.

SRC: Awodey §1.2

HU: Ezek mindazok a halmazfüggvény-tulajdonságok, amelyeket az absztrakt függvényfogalomhoz figyelembe akarunk venni — kompozíció és identitások.
EN: These are all the properties of set functions that we want to consider for the abstract notion of function—composition and identities.
SRC: Awodey §1.2

HU: Így most „absztrakció útján el akarunk távolítani" mindent mást, úgy mondható.
EN: Thus, we now want to "abstract away" everything else, so to speak.
SRC: Awodey §1.2

EN: That is what is accomplished by the following deﬁnition.
