GitHub Pages bekapcsolása (egyszer, ~2 perc)

  1. Repo: github.com/jhegedus42/Szima
  2. Settings → Pages
  3. Source: GitHub Actions (a workflow a cursor/literature-aaa6 ágon van)
  4. Merge után vagy workflow futtatás után: https://jhegedus42.github.io/Szima/literatura.html

Vercel (alternatíva)

  1. vercel.com/new → Import Git Repository → Szima
  2. Root Directory: docs
  3. Framework: Other (statikus)
  4. Deploy → kapod a *.vercel.app URL-t

Cloudflare Pages (alternatíva)

  1. Cloudflare Dashboard → Pages → Connect Git → Szima
  2. Build output directory: docs
  3. No build command
